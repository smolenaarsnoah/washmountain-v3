-----------------------------------------------------
HOE VOEG JE EEN NIEUW PARTNERLOGO TOE?
-----------------------------------------------------
1. Plaats je nieuwe afbeelding in deze map ('images/logos/'), bijvoorbeeld 'redbull.png'.
2. Open het bestand 'data/logos.json' in de map 'data/'.
3. Voeg een nieuw regeltje toe, bijvoorbeeld:
   {
     "name": "Red Bull",
     "file": "redbull.png"
   }
4. Klaar! De website toont het logo nu direct automatisch in de bewegende balk op de homepage!
